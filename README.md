My Character Encyclopedia

Week 5 of terra

I made a Character Encyclopedia that has the characters of three games which are Brawlhalla, Streets of Rogue, and Weapon Balls. This Character Encyclopedia features many different characters which are about 125 characters between the three games.

I made this website because I wanted a way to keep track of all the many characters in the games even if there are wiki's.

How to use the website?
1. You open the website and choose one of the three games. You can also use the search bar to choose one of the games.
2. You can look at the different characters on the pages.
3. You should hover over the characters for effects. The Brawlhalla page has really nice effects so you should definitely check out that page.
4. For the Brawlhalla and Streets of Rogue pages you can click on the different buttons which are All, Good, Evil, and Other buttons. These buttons show which character fits the role you clicked on.
5. Click the "Go Back" button to go back to the main page.
6. Lastly, check out the different games and check out the different chracters.
